# Cycle 8: 自動献立生成

## 目的
登録済みレシピから1週間分の献立を自動生成する機能と、空きセルのみを自動で埋める機能を実装する。

## タスクリスト
- [ ] `MealPlanService` に自動生成ロジック追加
  - `AutoGenerateAsync` — 全セルをランダムに自動生成
    - レシピリストをシャッフル
    - 14 セル（7日 × 2食）にラウンドロビンで割り当て
    - 連続する日に同じレシピが来ないよう調整
    - 既存の MealPlan は上書き
  - `AutoFillAsync` — 空きセルのみを自動埋め
    - 既存の MealPlan を取得
    - 既に割り当て済みのセルはスキップ
    - 空きセルに対してのみランダム割り当て
- [ ] `MealPlanFunction` に追加エンドポイント
  - `POST /api/mealplans/auto-generate`
  - `POST /api/mealplans/auto-fill`
- [ ] フロントエンド
  - 献立ボードに「自動生成」ボタン追加
  - 献立ボードに「空きを埋める」ボタン追加
  - 確認ダイアログ（自動生成は既存データを上書き）
- [ ] 単体テスト
  - レシピ 0 件時のエラー
  - 自動生成で全セル埋まること
  - 自動生成で連続同一レシピがないこと
  - auto-fill で既存セルが維持されること

## 依存関係
- Cycle 7（献立ボード CRUD）

## アルゴリズム詳細

### auto-generate
```
1. グループの全レシピを取得（IsDeleted = false）
2. レシピが 0 件 → エラー
3. 既存の週間 MealPlan を全削除
4. レシピリストをシャッフル
5. 14 セルを順番に処理:
   a. 前のセルと同じレシピを避ける
   b. ラウンドロビンインデックスからレシピ選択
   c. MealPlan + MealPlanRecipe を作成
6. 結果を返却
```

### auto-fill
```
1. 既存の週間 MealPlan を取得
2. 空きセルを特定（MealPlan がないか、MealPlanRecipe が 0 件のセル）
3. 空きセルに対して auto-generate と同じロジックを適用
4. 既存セルはそのまま維持
5. 結果を返却
```
